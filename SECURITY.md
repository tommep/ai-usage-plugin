# Security reporting

Report credential exposure, unsafe authentication behavior, or other security
issues privately through [GitHub's vulnerability report form](https://github.com/tommep/ai-usage-plugin/security/advisories/new).

Include the app/CLI version, a description of the problem, and reproduction steps
using fictional data where possible. Do not send passwords, access tokens,
Keychain exports, provider credential files, or private conversations.

Ordinary bugs belong in GitHub Issues. Maintenance is best-effort; there is no
promised response time. The latest `main` branch is the active development version.
